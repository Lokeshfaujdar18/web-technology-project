Implementation summary

Changes made to this website for the JavaScript Practical Assignment. All five required features are implemented directly inside this file.

No.JavaScript TaskWhere Implemented on the Site
1Form Validation"Order enquiry" section (id="enquiry"). Validates Name, Email, Mobile, Quantity, and Delivery Date.
2Dynamic GreetingHero section (id="home"). A badge above the heading shows a time-based greeting.
3Dynamic Bill / Price Calculation"Estimate your order" section (id="cart"). Checkboxes for each book update a running total.
4Show / Hide Content"Book of the Month" section (id="featured"). A "Read more / Read less" button toggles extended book details.
5Dynamic Content / Image Change"Popular Books" section (id="books"). A spotlight card with Previous/Next buttons cycles through all 3 books.

1. Form Validation — Order Enquiry Form

Collects buyer name, email, mobile number, quantity, and preferred delivery date. JavaScript checks for empty fields, a letters-only name, a valid email pattern, a 10-digit mobile number, a quantity between 1 and 50, and a date that isn't in the past. Shows a success or error message and resets on success.

2. Dynamic Greeting

Reads the current hour with new Date().getHours() on page load and displays "Good Morning", "Good Afternoon", or "Good Evening" in a badge above the hero heading.

3. Dynamic Bill / Price Calculation

Python Programming (₹450), Web Technology (₹500), and Database Management (₹550) are selectable checkboxes. A "change" listener recalculates the total instantly as books are checked or unchecked.

4. Show / Hide Content

The Book of the Month card has a "Read more" button that toggles a hidden CSS class to reveal page count, format, and audience details. The label switches between "Read more" and "Read less".

5. Dynamic Content / Image Change

A book spotlight widget with Previous/Next buttons updates the displayed title, author, and cover color, cycling through all three featured books.
